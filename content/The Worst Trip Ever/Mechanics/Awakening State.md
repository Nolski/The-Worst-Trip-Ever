### Summary

An Awakened character has briefly broken free of the fantasy hallucination and perceives the real world as it truly is, losing access to their class features and spells while this state persists. Awakening is temporary, story-driven, and always allows a path back into the fantasy at a cost.

### When Awakening Occurs

When a character reaches **Lucidity 0**, the next Lucidity Check triggers one of the following:

- **Partial Awakening** (early/mid campaign)
- **Full Awakening** (late campaign or narratively appropriate)

DM chooses based on pacing.

---

### Partial Awakening

- Character perceives the real world briefly
- No loss of character sheet
- Apply **one level of Exhaustion**
- Character is aware that the fantasy is false, but cannot escape it

This state usually lasts minutes or less in-game.

---

### Full Awakening

Used sparingly.

While fully Awakened:

- Character **cannot use class features or spells**
- Character retains:
    - Ability scores
    - Proficiency bonus
    - Personality and memories

Treat the character mechanically as a **Commoner** for the duration.

This state should be **short and story-driven**, not punitive.
